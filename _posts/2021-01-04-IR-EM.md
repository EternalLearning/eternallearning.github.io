**Dynamic IR**
- Dependant on the switching activity of standard cell.
- Dynamic IR drop takes into account the instantaneous current drawn from the power grid in a switching event.

To resolve dynamic IR, we can
- space the standard cells apart so that the burden on given bump to feed many std cells decreases.
- We can also downsize cells to reduce instantaneous current demand.
- splitting output cap.
- inserting decap cells
- Also, solutions used for static ir drop are applicable here too.

**Difference between static IR and Dynamic IR**
Static IR: Takes avg demand current per instance and treats it as constant DC source at every node. It is a power grid resistive check at a DC simulation. It calculates the avg current drawn by cells from the power grid and assumes it to be steady at any given time. 
Dynamic IR: is a power grid resistive check at transient time simulation. It accounts for demand current drawn over a 20ns cycle period. 
Ways to fix static IR: 
1. Power distribution Network strengthning. (helps both). eg: widen/add more power straps, add more vias, near hotspots add more bumps, augment/reinforce PG near high current macros.
Ways to fix dynamic IR:
1. All Static Ir fixes help here as well along with it also try
2. decap cells, keep out margins of cells where toggling is high.
3. downsize the cells.
4. decrease load cap.
5. change to high vt cells if it is not impacting timing.
